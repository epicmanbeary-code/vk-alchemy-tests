# VK Video & Alchemy Автотесты (Appium + Java)

Проект содержит автоматизированные тесты для двух мобильных приложений:
- **VK Видео** (`com.vk.vkvideo`) – проверка воспроизведения видео (позитивный и негативный сценарии).
- **Алхимия: Головоломка** (`com.ilyin.alchemy`) – проверка увеличения количества подсказок после просмотра рекламы (два цикла).

Стек: Java 22, Maven, Appium, Selenide, TestNG.

## Требования

- **Java 22** (или совместимая версия)
- **Maven** 3.6+
- **Android Studio** (для создания эмулятора)
- **Эмулятор Android** с **API 30 (Android 11)** – обязательно, так как приложение Алхимия может быть нестабильно на новых версиях.
- **Appium сервер** (v2.0+), запущенный на `http://127.0.0.1:4723`
- **APK-файлы** приложений (поместить в `src/test/resources/apk/`):
  - `alchemy.apk` – приложение Алхимия
  - `vkvideo.apk` – приложение VK Видео

## 🚀 Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <url-вашего-репозитория>
cd vk-alchemy-tests
```

### 2. Подготовка APK-файлов

Скачайте APK VK Видео и Алхимии (например, с [APKPure](https://apkpure.net/) или прямо с устройства).  
Поместите их в директорию `src/test/resources/apk/`:

```
src/test/resources/apk/
├── alchemy.apk      # Приложение Алхимия
└── vkvideo.apk      # Приложение VK Видео
```

> **Важно:** APK-файлы не включены в репозиторий из-за большого размера. Добавьте их вручную.

### 3. Создание эмулятора Android API 30

1. Откройте **AVD Manager** в Android Studio.
2. Нажмите **"Create Virtual Device"**.
3. Выберите устройство (например, **Pixel 4**).
4. Выберите образ системы с **API 30** (Android 11.0). Если его нет, скачайте через ссылку "Download".
5. Задайте имя (например, `Pixel_4_API_30`) и запустите эмулятор.

> Убедитесь, что эмулятор запущен и доступен (можно проверить командой `adb devices`).

### 4. Запуск Appium сервера

```bash
appium
```
или используйте **Appium Desktop** с настройками по умолчанию.

### 5. Проверка конфигурации (опционально)

В файле `BaseTest.java` при необходимости укажите версию платформы и имя устройства:

```java
caps.setCapability(MobileCapabilityType.PLATFORM_VERSION, "11.0");
caps.setCapability(MobileCapabilityType.DEVICE_NAME, "Pixel_4_API_30");
```

Если эмулятор единственный, можно оставить `"Android Emulator"`.

## 🧪 Запуск тестов

Выполните в терминале из корня проекта:

```bash
mvn clean test
```

Результаты будут выведены в консоль, а также сохранены в `target/surefire-reports/`.

## 📝 Описание тестов

### 🧩 AlchemyHintsTest

1. Нажать **"Play"** в главном меню.
2. Открыть окно подсказок (клик по счётчику в правом верхнем углу).
3. Нажать **"Watch"** для просмотра рекламы.
4. Дождаться завершения рекламы (обрабатываются различные варианты: крестик, кнопка CAT, окно награды).
5. Повторить шаги 2–4 ещё раз.
6. Проверить, что количество подсказок увеличилось на **2** (итоговое = начальное + 2).

### ▶️ VkVideoTest

- **Позитивный тест**: включить интернет, открыть первое видео, убедиться, что плеер появился и остаётся видимым 15 секунд.
- **Негативный тест**: отключить Wi-Fi и мобильные данные, открыть видео, дождаться сообщения об отсутствии интернета.

## ⚠️ Возможные проблемы и решения

| Проблема                                       | Решение                                                                                              |
|------------------------------------------------|------------------------------------------------------------------------------------------------------|
| Приложение Алхимия закрывается после рекламы   | Убедитесь, что эмулятор использует **API 30 (Android 11)**. В `BaseTest` можно явно указать версию. |
| Тест VK Видео не находит видео                 | Локаторы могли устареть. Используйте **Appium Inspector** для обновления `By.xpath` в `VkVideoTest`. |
| Appium не подключается                          | Проверьте, что сервер запущен на `127.0.0.1:4723` и эмулятор работает (`adb devices`).               |
| Тесты зависают на рекламе                       | В коде заложены таймауты и обработка различных элементов. Если реклама уникальна, добавьте логирование и скорректируйте условия в `waitForAdCompletion()`. |
